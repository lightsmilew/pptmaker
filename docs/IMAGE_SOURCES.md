# Folio 主题图片与来源

当前内置 **42 张**经过人工主题与画面检查的照片，随后端 wheel 离线安装。生成时不访问外部图片服务。

图片来自 Wikimedia Commons，每项保留原始来源、作者与许可。导出的对应幻灯片备注写明来源、署名、许可和“居中裁剪与缩放”。CC BY-SA 素材及其裁剪版本继续遵循原许可；演示内作为独立图片素材使用。

主题图片是示意素材，不作为事实证据，也不代表用户材料中的特定人物、地点、设施或产品。当前没有文生图、实时图库搜索或用户图片嵌入能力；上传图片用于参考资料识别。

依据官方 [Imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo) 获取图片地址与 extmetadata 许可信息；图库筛选脚本 `scripts/curate_slide_photos.py` 输出候选到 `storage/photo-curation`，必须审阅画面、主题、来源和许可后再更新随包图库。禁止以搜索分类替代画面检查。
