## 选择和实际生成

`app/tools/design_catalog.py` 提供 16 种风格，以及四种编排和三档密度；认证 API 将同一目录提供给创作方案页面。新增风格要定义用途、配色、版式家族，并验证色彩对比和真实渲染，不能只给前端增加一个名字。

`slide_scene.py` 根据页类型、对比 / 流程语义、内容量、所选编排和页面位置选用测量过的模板：单栏、双栏、三栏、侧栏标题、分段列表、模块网格、流程线、重点结论，另有封面 / 目录 / 图表 / 表格。三个封面构图为边线、右侧色块和宽幅双线。部分人文与编辑主题采用宋体标题，其余采用微软雅黑；缺失字体时预览使用本机可用字体，PowerPoint 则按系统字体回退。

通用内容在自动模式下交替编排；有明确语义时可以连续使用相同结构，长内容也可能回退到更宽的双栏。图表必须有真实数据；缺少证据时回退文本，不填入装饰性假数字。舒展 / 适中 / 充实控制写作偏好和预算，没有强行裁切正文来保证固定字数。

并行任务从完整大纲读取页序，不因只加载当前页而把每页当作第一页。模型多写的内容组会按所选密度合并相邻标题与解释，保留其全部文字；无法容纳时仍走正常排版检查 / 修订，不静默删除。

预览 PNG 与可编辑 PPTX 共用 scene 和换行测量。测试检查文字保留、画布边界、对比与重叠；这些不能证明审美或事实质量，仍需查看实际样张。当前没有外部 PPTX 母版导入、远程字体、图库照片或自动插图；不要将风格示意称为第三方模板实物。
