# Folio 设计系统

版本：2026-10-07。用户已认可的主页是全部页面的基准。新增页面和维护旧页面都沿用这套规范，不另建视觉主题。

## 基础风格

安静的编辑工作台：纸白画布、浅灰绿侧栏、墨绿操作、文档式排版、留白与细边框。可选演示主题只影响真实样张和幻灯片，不改变导航、表单和公共控件。

| 角色 | 色值 | 用途 |
|---|---|---|
| Paper | `#FAF9F6` | 全页背景 |
| Surface | `#FFFFFF` | 表单、列表、预览控件 |
| Sidebar | `#F0F1EB` | 固定侧栏 |
| Sage | `#EDF1E8` | 说明区、选中页面、权益区 |
| Ink | `#27342D` | 标题、正文 |
| Primary | `#29483E` | 主按钮、品牌、强调 |
| Border | `#DFE4DA` | 分隔线、输入、卡片 |
| Muted | `#74816F` | 辅助说明 |

CSS 变量为 `--folio-paper/ink/green/sage/border/muted`，集中在 `frontend/src/index.css`。Tailwind 可使用 `folio` 语义色。警告和错误可使用低饱和琥珀 / 红色；不要按每种页类型随机分配粉、紫、青色。

## 布局

全部业务页使用 `StudioShell`，内含品牌、侧栏、面包屑、个人中心、页脚和移动导航。禁止单独重新实现页头或侧栏。

侧栏桌面宽 224px，中等屏 194px；顶栏 68px；内容最大 1190px，演示页适当放宽至 1400px。内容桌面左右 48px，中等屏 28px，手机 20px。页面标题与主要内容之间 28–32px；同层卡片间 18–22px。

650px 以下折叠侧栏，菜单展开后提供遮罩和关闭操作；950px 以下将演示页面列表改为横向条。工作空间桌面三列、中等屏两列、手机一列。资料表单桌面两列、手机一列。

## 字体与文案

使用系统 sans 字体栈，无远程字体请求。主页标题 26–37px，项目标题约 26px；段落 12–13px，组件标题 12–14px，标签 10–11px。字重以 400 / 500 / 600 为主。少量大写英文 eyebrow 提供章节线索，不替代中文标题。

文案描述用户能完成的事。模型、缓存、实现细节留在个人中心的用量或展开详情中，不填满主页。等待、空结果、失败和成功状态都应清楚，不以随机鼓励或假数字替代状态。

品牌：Folio；标语：Let your ideas unfold.；Logo 统一引用 `/folio-mark.svg`。项目标题随具体内容变化，其他页使用简洁、带创作意象的浏览器标题。

## 公共组件

- `Button`：主要按钮墨绿，次要按钮细边框或纯文本；约 5–7px 圆角，12px 字号，图标 14–16px。每个区域保留一个明确主操作。
- `Card`：白色表面、细边框、约 7–10px 圆角，无浮起或大阴影；不是每段文字都需要卡片。
- `Input / Select / Textarea`：统一 `studio-field`，浅纸色背景、细边框、5px 圆角、墨绿焦点。传入 `label` 自动关联 ID；自定义标签须用 `htmlFor` 或 `aria-label`。
- `Badge`：小尺寸、低饱和状态色；业务状态使用 `pageUtils.statusLabels`。
- `StepIndicator`：单行小编号与细分隔，完成态小勾，不使用大图标卡片。
- `PageCard`：紧凑页面条，编号 / 标题 / 状态，选中态浅灰绿与细墨绿边。
- `Tabs / Modal / Progress`：统一墨绿焦点与状态，克制的圆角和过渡；弹窗须使用 Radix 的键盘及焦点管理。

示例结构：

```tsx
<StudioShell section="workspace" {...shellProps}>
  <div className="page-heading-row">
    <div className="studio-heading">
      <p className="eyebrow">YOUR COLLECTION</p>
      <h1>每一次表达，都有迹可循。</h1>
      <p>一行清楚的页面说明。</p>
    </div>
    <Button>主要操作</Button>
  </div>
  {/* 按信息结构组织内容，复用 Card / form-grid / section-heading */}
</StudioShell>
```

## 交互与验收

控件使用语义按钮或链接，可用键盘访问；图标按钮提供中文名称。所有可交互控件有可见 focus。checkbox 不能只让鼠标看见选中效果；保存中禁用重复提交，资料验证错误可读。

屏幕阅读状态使用 `role=status` / `role=alert`；筛选与预览切换提供 pressed，导航使用 current。空页包含原因和可用行动。归档提供正常恢复流程，不以永久删除代替历史整理。

尊重 reduced motion，避免循环漂浮、发光、全屏渐变、玻璃拟态、彩色阴影、过大的圆角或炫技的加载画面。不能通过重映射 `indigo` 等通用颜色名来掩盖旧样式，应直接使用语义色和共用组件。

交付前查看 1440px 桌面与 390px 手机布局，检查长标题、空状态、加载、报错、真实历史与键盘焦点。新增页面必须保持主页的导航、按钮、卡片与字体一致；截图不应依赖虚构的用户或用量数据。
